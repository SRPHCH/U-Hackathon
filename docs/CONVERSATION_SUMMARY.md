# สรุปบทสนทนาและความต้องการทั้งหมด (Handoff สำหรับ AI/นักพัฒนาคนถัดไป)

เอกสารนี้สรุปทุกอย่างที่เจ้าของโปรเจกต์ (ผู้ใช้) สั่งและตัดสินใจไว้ตลอดการทำงานร่วมกับ Claude เรียงตามลำดับเวลา
พร้อมเหตุผล และสิ่งที่ยังค้างอยู่ ใช้ควบคู่กับ `README.md` (ซึ่งอธิบายโครงสร้างโค้ดและวิธี build)

- ผู้ใช้เขียนคำสะกดผิดบ่อย (เช่น Scretary, Enterpuner) ให้แก้ให้ถูกโดยไม่ต้องถาม

## 1. รอบปรับดีไซน์หน้า Landing (ใช้สกิล impeccable)

ลำดับคำสั่งของผู้ใช้ และผลลัพธ์:

1. **"ปรับ UX/UI ไม่ให้เป็น AI slop"** → ออกแบบใหม่เป็นโทนกระดาษอุ่น/แดงราสเบอร์รี่, ลบสิ่งที่ดูเป็น AI ทั่วไป
   (ตัวอักษรไล่สี, ป้าย kicker/เลขกำกับหัวข้อ, การ์ดเหมือนกันทั้งหมด, จุดกะพริบ, glass blur, อิโมจิเป็นไอคอน)
2. **"ดูเก่าไป อยากได้ Design modern กว่านี้ Theme ขาว/ชมพูพาสเทล"** → เปลี่ยนเป็นพื้นขาว + ชมพูอ่อนหลายระดับ,
   มุมโค้งใหญ่ (20–32px), แถบเมนูลอยเป็นแคปซูล, ฟอนต์ Anuphan, การ์ดเอเจนท์แบบ bento ขนาดไม่เท่ากัน
3. **"เปลี่ยนจากชมพูเป็นขาวเนียน"** → ผู้ใช้สั่งแล้ว **สั่งกลับ** ("เปลี่ยนกลับเป็นชมพู ตอนนี้ขาวไปหมด")
   → **ข้อสรุป: ธีมหน้า Landing คือขาว/ชมพูพาสเทล** เฉพาะกรอบหลังตัวมดให้เป็นพื้นโปร่งใส (ไม่มีกล่องชมพู)

## 2. ตัวมาสคอตมด 3D (ไฟล์ `ant-studio.html` ที่ผู้ใช้ส่งมา)

ผู้ใช้ส่ง `ant-studio.html` (สตูดิโอสร้างตัวละคร 3D ด้วย Three.js) และสั่ง: ใส่ "มด สีแดง Gentleman" แทนที่ภาพใน hero

ข้อกำหนดที่ผู้ใช้สั่งตามลำดับ (ทั้งหมดอยู่ในโค้ดแล้ว):

- มดอยู่ใน hero ข้างหัวข้อ บนพื้นโปร่งใส **ลากหมุนไม่ได้ ขยับเองตลอด** แต่ **กดที่ตัวเพื่อแกล้งได้**
  ข้อความใต้ตัว: **"กดเพื่อแกล้ง"** (ไม่มีพื้นขาวรองหลัง)
- **ท่าตอนเพิ่งเข้าเว็บ**: เริ่มหันหน้าไปทางขวา → โดดสองครั้งมาตรงกับผู้ใช้ → เอียงตัวไปทางซ้ายของผู้ชม (ขวามือของมด)
  → มีอิโมจิ 👋 งอกออกมาโบกแล้วหุบ → กลับไปขยับตามปกติ
- **ตอนปกติ**: ขยับไม่หยุด หันซ้ายขวา โยกตัวเหมือนโบกมือทักทายแต่ไม่มีมือ (ไม่เอาท่าโดดมาก)
- **ท่าแกล้ง (เรียงลำดับ)**:
  1. โดนเตะ → **ล้มหงายหลัง/กระเด็นไปด้านหลัง** (ไม่ใช่ล้มข้างๆ) กระเด้งตอนตก
  2. นอนตาลอย → กระโดดลุก
  3. หัวร้อน: กระทืบโดด ตัวสั่น มีควัน สัญลักษณ์โกรธ แสงแดง
  4. **มือของผู้ใช้ยื่นแบงก์จากขอบล่างจอ** (ไม่ใช่แขนจากด้านข้าง) อยู่ **ไกลจากมด ไม่บังหน้า**
  5. มด **กระโดดเข้ามาดูเงิน → รับไป → กระโดดกลับที่เดิม** แล้วเย็นลง
- มดตัวนี้ = **Secretary** (ตัวหลักของทุกทีม)
- ผู้ใช้ย้ำ: iframe/ไฟล์แยกอาจไม่ขึ้นในบางที่ดู (ปัญหา "มดหาย") → ต้องเปิดผ่านเบราว์เซอร์/เซิร์ฟเวอร์จริง

## 3. ปรับเนื้อหาหน้า Landing (copy) — ผลสุดท้าย

- ลบ: แถบเลือกประเภทธุรกิจ + แผงพรีวิวสีชมพูใต้ hero, ปุ่ม "นัดดูเดโม" ทุกที่, ข้อความสถานะ "ทำงานอยู่" ฯลฯ ในการ์ดเอเจนท์,
  รหัสย่อ FN/LG/MK/MI/DL/OP ในการ์ดและแผนผัง, ป้าย "ใหม่ Oracle Agent"

  ตั้งแต่การเงิน การตลาด กฎหมาย ไปจนถึงข่าวสารในตลาด และทำงานต่อเนื่องโดยไม่ต้องรอคำสั่ง"

- หัวข้อ Agents: **"เป็น Solo Entrepreneur แต่มีทีมครบทุกฝ่าย"** (ลบย่อหน้าใต้หัวข้อ)
- ส่วน Advisor → **Secretary**: "มี Secretary เลือก Agent ให้ ไม่ต้องนั่งเลือกเอง"
  ย่อหน้า: "Secretary วิเคราะห์ประเภทสินค้า ช่องทางขาย และแนวทางการทำธุรกิจของคุณ แล้วเรียกใช้ AI Agent ด้านที่เหมาะสมให้
  ช่วยบริหารจัดการ Token ได้อย่างคุ้มค่า และกำหนดว่า Agent ตัวไหนควรส่งข้อมูลต่อกัน"
- ส่วน Oracle → **"ช่วยประเมินแนวทางการเติบโตของตลาดคุณ"** ใช้ชื่อ **Market & Industry Update**
- **Pricing**: เหลือการ์ดเดียว **Plan Demo ฿0** (Agent หลักครบ 6 ตัว, Secretary จัดสรร Token อัตโนมัติ,
  Market & Industry Update รายงานแนวโน้มรายสัปดาห์); ลบข้อความ "ทดลองใช้ฟรี 14 วัน..."; เก็บปุ่มรายเดือน/รายปีไว้ แสดง "ถูกกว่า 0%"
- **FAQ**: หัวข้อใหญ่กึ่งกลาง → รายการคำถาม → บรรทัด "ไม่พบคำตอบที่ต้องการ? ติดต่อทีมงานได้ที่ XXX@gmail.com"
  (อีเมลทุกจุดเปลี่ยนเป็นตัวเดียวกัน — **ยังเป็น placeholder**); เหลือ 4 ข้อ (ตัด Token/เชื่อมต่อร้านค้า/ความปลอดภัย)
- **CTA ท้ายหน้า**: "ให้ทีม AI ช่วยพาธุรกิจของคุณไปให้ถึงฝัน เริ่มได้ตั้งแต่ตอนนี้" +
  "แค่สมัคร Plan ก็เริ่มใช้งานได้ทันที ไม่ต้องผูกกับร้านค้า"
- **หลักภาษา**: ใช้ "Agent", "AI", "Token", "Secretary" (ไม่ใช้เอเจนท์/เอไอ/โทเคน/Advisor/Oracle ในเนื้อหา), เว้นวรรคไทย-อังกฤษ
- ปุ่ม CTA/เข้าสู่ระบบ ทั้งหมดพาไป Workspace (`#app`)

## 4. AI Workspace (หน้าใช้งานแชต)

คำสั่งของผู้ใช้ตามลำดับ:

1. **"เข้ามาแล้วมี UI เหมือน Grok bot (ภาพอ้างอิงแอปชื่อ Revo) แต่มี Bot รอ 6 ตำแหน่ง จัดเป็นหมวด 'ทีม 1'
   เปลี่ยนชื่อทีหลังได้ และสร้างเพิ่มได้"** → ซ้ายรายชื่อ/ค้นหา/+; ขวาแชต; ธีมมืด
2. **"Workspace ต้องต่อกับ Landing page" / "มัน Block คู่ กดข้ามกันไม่ได้"** → รวม Workspace เข้าไฟล์ `solora-landing.html`
   เดียว สลับด้วย hash (`#app` / `#top`) เพราะลิงก์ข้ามไฟล์ถูกบล็อกในที่ดูแบบ snapshot
3. **ใช้ระบบ 3D มดเป็น Profile ของ AI ทุกตัว**; **ตอนเพิ่มพนักงานให้เลือกหน้าที่ได้อย่างเดียว** แต่ละหน้าที่มี pattern การเริ่มคุย/ถาม
   ของตัวเอง; **ทุกทีมต้องมี Secretary เป็นตัวกลางและบังคับสร้าง**; **เอาช่อง "ให้ Bot ทำอะไร" ออก**;
   **เลือกสีได้ (เปลี่ยนในโปรไฟล์ 3D ด้วย)**; ตัวอื่นให้ปรับแต่งตามความเหมาะสม **โดย base on มดตัวเดิม** (ใช้ชุดอุปกรณ์ในสตูดิโอ)
4. **ตอนพิมพ์**: AI หันหน้ามองลงมาที่ช่องพิมพ์ ขยับตัวเล็กน้อยให้ดูมีชีวิต —
   ผู้ใช้แก้ว่า **ต้องเป็นรูป Profile 2 จุด (รายชื่อซ้าย + หัวแชต) ไม่ใช่ตัวลอยแยก**: ตัวซ้ายมองเฉียงลง ตัวบนก้มลงตรงๆ,
   **ไม่ต้องโดด ไม่ต้องกดได้**
5. **ตอนส่งแล้วรอคำตอบ**: ทำท่ากำลังทำงานตามอาชีพพร้อมอุปกรณ์ (Secretary ถือโทรศัพท์บ้านสีดำแนบหูเหมือนคุยสาย,
   Finance นับเงิน, ที่เหลือให้คิดเอง → ดูตาราง role ใน README)
