วิธีใช้ Antistant

ตอนนี้เปิดให้ใช้งาน 2 ตัว คือ Secretary และ Legal Agent ส่วน Agent ตัวอื่นติดกุญแจไว้ กำลังพัฒนาและจะเปิดเร็วๆ นี้
  1. Secretary จะทักทายแล้วถามเรื่องร้านทีละข้อ กดเลือกคำตอบในการ์ด หรือพิมพ์/พูดตอบเองก็ได้
  2. Legal Agent จะเข้ามาร่วมคุยเรื่องกฎหมายในแชตเดียวกัน แล้วสรุปสิ่งที่ร้านต้องทำไว้ในแชตของตัวเอง
  3. ปุ่ม + ใช้แนบไฟล์ หรือเลือก Agent มาช่วยตอบในแชตที่เปิดอยู่
  4. ไมค์ พูดแทนการพิมพ์ ส่วนปุ่มคลื่นเสียง คุยด้วยเสียงแล้วให้ AI อ่านคำตอบให้ฟัง
  5. เอาเมาส์ชี้ข้อความของ AI เพื่อกด ดี / ไม่ดี / คัดลอก / ฟังเสียง
  6. รูปเฟือง ⚙ การตั้งค่า มุมซ้ายล่าง ใช้เลือกเสียงที่ AI ใช้อ่าน ความเร็ว ภาษาไมค์ และงบ Token ส่วนงาน Token และภาพรวมดูได้จากเมนูด้านบน
